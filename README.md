# teoteloexplica.com

Web de [@teo.teloexplica](https://www.instagram.com/teo.teloexplica/): dos guías gratis: el manual práctico del kit de emergencia de 72 horas (`index.html`) y la guía de la huelga general del 11-N (`huelga.html`).

La genera `instagram/web/build_web.py` del repositorio de trabajo a partir del manual. No editar `index.html` a mano.

En calidad de Afiliado de Amazon, obtengo ingresos por las compras adscritas que cumplen los requisitos aplicables.
